Generated by `scripts/compare_cf_hybrid.py` from the runs' raw recommendation and ground-truth files; do not edit by hand.

Same test repositories and folds in both methods of each pair (checked). Hybrid = run A (readme_8k_desc20 CNBN seeds, KG off); CF-only = TopFilter half mode, KG off.

| view | input the method sees | scored against |
|---|---|---|
| CF-only | first half of the repo's own topics | the held-back second half |
| hybrid, matched | README (via 5 CNBN seeds); the first half is removed from its list | the same held-back second half |
| hybrid, own | README (via 5 CNBN seeds) | all of the repo's topics |

The matched view puts both methods on the same target, but not the same information: CF-only is given half of the owner's topics, the hybrid none (the cold-start case it exists for). Values are the mean over the ten folds of the fold means, std in brackets. Δ = hybrid matched − CF-only.
